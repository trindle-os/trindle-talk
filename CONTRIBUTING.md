# Contributing

Thank you for being interested in Talk.

## Reporting a bug

A clear description helps most. Please tell us:

- what you did,
- what you expected to happen,
- what happened instead,
- your version of Talk and of Trindle, and your setup (which language you speak, whether Read back was on).

Report bugs at [trindle.buildmorphic.com](https://trindle.buildmorphic.com).

## Code changes

Talk is set up as a one-person project, so we do not take code changes as pull requests. That is only how it is arranged, and it is not a judgement on your idea. If you have fixed something or built something, describe it at [trindle.buildmorphic.com](https://trindle.buildmorphic.com) and we will look at it properly.

## Security problems

Please report these privately, not in a public issue. See [SECURITY.md](SECURITY.md).

## Forking

Talk is free software. You are welcome to fork it and change it under the terms of the licence in [LICENSE](LICENSE).
