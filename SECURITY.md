# Security

## Supported versions

| Version | Supported |
|---|---|
| 1.0.x | Yes |
| Older | No |

## Reporting a problem

Please report security problems through the Trindle community at https://trindle.buildmorphic.com, and mark the report as a security problem. If you would rather not post it where others can see it, email distro@trindle.org.

Please do not open a public issue for a security problem until it has been fixed.

## What to expect

Talk is looked after by a very small team. We will reply as soon as we can, usually within a week, tell you whether we agree it is a problem, and tell you when it is fixed. We will credit you in the changelog if you want that.

## What Talk does with your voice

Talk listens only after you press its icon. Your voice is processed on your own computer and is not written to disk. The only network use is a one-off download of the speech files, which are checked against pinned checksums before use.
